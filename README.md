# ExamiaLink Étudiant

Application Android pour les étudiants ExamiaLink.

**Télécharger l'application :**
https://github.com/henrijoel-cyber/examialink-telechargement/raw/main/EXAMIA_ETDT.apk

## Installation

1. Ouvre le lien ci-dessus sur ton téléphone Android et télécharge le fichier `EXAMIA_ETDT.apk`.
2. Ouvre le fichier téléchargé. Si Android te le demande, autorise l'installation d'applications depuis cette source (ton navigateur).
3. Appuie sur **Installer**, puis ouvre l'application.

L'application nécessite une connexion internet.
