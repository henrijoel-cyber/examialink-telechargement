# ExamiaLink Étudiant

Application Android pour les étudiants ExamiaLink.

**Télécharger l'application :**
https://github.com/henrijoel-cyber/examialink-telechargement/releases/latest/download/ExamiaLink-Etudiant.apk

## Installation

1. Ouvre le lien ci-dessus sur ton téléphone Android et télécharge le fichier `ExamiaLink-Etudiant.apk`.
2. Ouvre le fichier téléchargé. Si Android te le demande, autorise l'installation d'applications depuis cette source (ton navigateur).
3. Appuie sur **Installer**, puis ouvre **ExamiaLink Étudiant**.

L'application nécessite une connexion internet.
